# Genomic Data Science: FASTA Parser & GC Content Analyzer

A professional-grade bioinformatics project designed to parse FASTA DNA sequence files, compute essential genomic metrics (Sequence Length and GC Content), and visualize base composition.

## Features
* **Pure Python FASTA Parsing:** Robust handling of biological sequence data without external library dependencies (optimized for local security policies).
* **Genomic Metrics Calculation:** Accurately computes total sequence length and GC content percentage.
* **Data Visualization:** Generates and saves a clean Matplotlib bar chart illustrating DNA base (A, T, G, C) distribution.

## Output
* **GC Content:** 45.83%
* **Sequence Length:** 24 bp
* **Visualization Plot:** Saved as `dna_composition_plot.png`
